Wireless foundations

How a wireless link works, from bits to antennas: the communication model, propagation, link budgets, antennas, the metrics everyone uses, and what real hardware does.

  • 6 tutorials
  • Diagrams, interactive models and self-checks

Start here if you are new to wireless. The six tutorials build on each other, from the basic model of a link to the imperfections of real hardware.

  • 1. Communication modelThe communication modelEvery wireless link turns bits into a radio wave, sends it through a channel that distorts it and adds noise, and turns it back into bits.9 min · model: Noisy constellations
  • 2. PropagationWireless propagationBetween two antennas, a radio wave spreads out, bounces, bends and scatters. The result is a channel that loses power with distance and fades as you move.10 min · model: Coverage explorer
  • 3. Link budgetLink budgetsA link budget adds up every gain and loss between two radios to answer one question: will the signal arrive strong enough to beat the noise?8 min · model: Link budget calculator
  • 4. AntennasAntennasAntennas turn currents into radio waves and decide where the energy goes. Put many together and you can steer a beam without moving anything.12 min · model: Steer an array
  • 5. Performance metricsPerformance metricsSNR, SINR, BLER, spectral efficiency, outage, bits per joule: the measures that papers, standards and engineers use to say whether a wireless system is any good.8 min · model: Outage explorer
  • 6. Hardware impairmentsHardware impairmentsReal radios add distortion that grows with the signal itself. Raising the power can’t remove it, so it sets a ceiling on every link.9 min · model: Find the capacity ceiling
