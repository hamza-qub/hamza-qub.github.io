The communication model

Every wireless link turns bits into a radio wave, sends it through a channel that distorts it and adds noise, and turns it back into bits.

The chain every link follows

In 1948 Claude Shannon drew a diagram that still describes every link, from Wi-Fi to 6G. The transmitter turns information into a radio wave; the receiver undoes each step in reverse.

  • compressSource codingRemoves redundancy so fewer bits carry the same information. MP3, JPEG and video codecs do this.
  • protectChannel codingAdds redundancy back, in a controlled way, so the receiver can fix errors. 5G uses LDPC and polar codes.
  • transmitModulationMaps groups of bits to symbols, and symbols to a waveform the antenna can radiate.

Bits become symbols

A modulator sends several bits at once by picking one point from a set called a constellation. Each point is a complex number: its horizontal part rides on a cosine carrier, its vertical part on a sine.

Key idea

More points carry more bits per symbol, but points that sit closer together are easier for noise to confuse. Every modulation choice trades speed against robustness.

The channel: y = h·x + n

Between the antennas, the channel does two things to every symbol. Fading multiplies it by a complex gain h, which shrinks and rotates it. The receiver’s electronics then add random noise n.

Noise causes errors

The receiver decides correctly as long as the noise does not push a symbol across a decision boundary into a neighbour’s region. Try it.

Things to try:

  • Start with 16-QAM at 14 dB and lower the SNR. Errors appear first between neighbouring points.
  • Switch to 64-QAM at the same SNR. The points are closer, so the same noise causes far more errors.
  • Switch to QPSK. It is almost error-free at 14 dB, but carries only 2 bits per symbol instead of 4.

How fast can a link go?

Shannon also proved a limit. However clever the coding and modulation, no link can carry more than

bits per second over a bandwidth of B hertz. There are only two ways to go faster: more bandwidth, or more SNR.

Key idea

At high SNR, every 3 dB of extra SNR buys only about one more bit per second per hertz. Bandwidth grows the rate in direct proportion, which is why 5G and 6G chase wide bands at higher frequencies.

More detail: the wideband limit

With a fixed power P and noise density N₀, widening the band does not raise the rate forever. As B grows, the SNR P/(N₀B) falls, and the capacity approaches the wideband limit

Equivalently, reliable communication needs , or −1.59 dB, however much bandwidth is available. This is called the Shannon limit.

Key takeaways
  • Every link follows the same chain: source coding, channel coding and modulation, mirrored at the receiver.
  • Modulation maps bits to constellation points. More points carry more bits but need more SNR.
  • The channel multiplies each symbol by a complex gain and adds Gaussian noise.
  • Shannon capacity, B·log₂(1 + SNR), bounds every scheme. Bandwidth raises it linearly, SNR only logarithmically.

Check your understanding

How many bits does one 256-QAM symbol carry?

log₂256 = 8 bits.

A link has 20 MHz of bandwidth and an SNR of 15 dB. What is its Shannon capacity?

SNR = 10^1.5 ≈ 31.6, so C = 20 × 10⁶ × log₂(32.6) ≈ 20 × 10⁶ × 5.03 ≈ 100 Mbit/s.

Why does a channel decoder need the redundancy that the source encoder removed?

It doesn’t need the same redundancy. Source coding removes natural, uncontrolled redundancy; channel coding adds structured redundancy that the decoder knows how to use to find and correct errors.
